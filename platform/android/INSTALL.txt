yomu reads .epub, .txt, and DRM-free .mobi and .azw3 books on a jailbroken Sony DPT-RP1.

The device runs Android 5.1.1. Root it so adb install works (HappyZ/dpt-tools). This package is an armeabi-v7a APK. Copy yomu.apk to the computer you use for adb, then:

  adb install -r yomu.apk

Open yomu from the launcher. The Android framework stays running. The app draws into a bitmap and asks the panel to refresh that rectangle on every update. The screen stays in landscape, and the frontlight is not touched. There is no frontlight on this device.

Books go in yomu/books on internal storage. That is the yomu/books directory on the external-storage root, usually /sdcard/yomu/books. yomu creates the directory. The 文字 screen scans /system/fonts and lists every face that has kana and kanji. A .ttf, .ttc, .otf, or .otc uploaded on the transfer page, or copied into yomu/fonts, is listed too. The transfer page shows that folder. The log is yomu/yomu.log next to that folder.

Swipe down from the top of the library and choose 転送. A browser on the same Wi-Fi can upload and download files in yomu/books. The server tries port 80, then 8080, then 3000, then 4000, then 5000, then any free port. This app cannot bind port 80. The screen shows the address it is using, such as http://yomu.local:8080/, and the numeric address. There is no password. Tap 戻る to leave the screen. The server keeps running until yomu exits.

The power button sleeps the device. yomu is still running when the screen wakes. 終了 on the library menu exits yomu.
